# **Zarì Ethnics | Interactive Showroom & Atelier Landing Page**

Welcome to the official source repository for **Zarì Ethnics v3**. This website features an interactive product catalog showcase, an ultra-high-definition fabric analyzer, live operational status monitoring, and a secure backend workspace for live content management.

## **📁 Repository Layout**

The repository files sit directly on the root level to guarantee high performance and direct path loading:

├── index.html                 \# Main self-contained production landing page (Tailwind, JS)

├── Zari Qr code-01.svg        \# Print vector asset for showroom placements

## **🛠  Content Management & Live Updates**

The website features a built-in **Premium Atelier Command Center** accessible directly through the live webpage without any database subscription overhead.

### **How to access the Admin Panel:**

1. Scroll down to the **Boutique Selection Gallery** section.  
2. Click on **Atelier Command Center** in the dark panel.  
3. Enter your authorized administrator key credentials .  
4. From here, you can crop new photos, edit prices, update sizing formats, and click **Save Changes Directly to GitHub** to trigger an automated live compilation and deployment.
