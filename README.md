Zari Ethnics | Interactive Showroom & Atelier Landing Page

Welcome to the official source repository for Zari Ethnics v3. This website features an interactive product catalog showcase, an ultra-high-definition fabric analyzer, live South African Standard Time (SAST) operational status monitoring, and a secure backend workspace for live content management.

└── meta_data.docx            # Raw copy of original catalog pricing spreadsheets


🛠️ Content Management & Live Updates

The website features a built-in Premium Atelier Command Center accessible directly through the live webpage without any database subscription overhead.

How to access the Admin Panel:

Scroll down to the Boutique Selection Gallery section.

Click on Atelier Command Center in the dark panel.

Enter your authorized administrator key credentials.

From here, you can crop new photos, edit prices, update sizing formats, and click Save Changes Directly to GitHub to trigger an automated live compilation and deployment.
